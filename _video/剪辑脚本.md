## 2. 统一镜头语言（四拍）

| 拍 | 画面 | 作用 | 时长 |
|---|---|---|---|
| ① 建立 | 整窗 100%，不推不摇 | 确认「这是真系统」 | 1.0–1.2s |
| ② 输入 | 推近输入框 1.5×，慢推 ease-out | 打字机逐字，留光标 | 2–2.8s |
| ③ 等待 | 保持不动，只让 Reasoning 转 | 0.4 秒停顿比任何转场都真实 | 0.4s |
| ④ 结果 | 平移到输出区放大 1.25–1.4× | 停在完整输出上再淡出 | 剩余 |

三条硬规则：

- **不变速**。加速过的录屏一眼看得出，反而像假的。
- **不加 UI 壳**。不做弹窗边框、不加光斑、不加光标特效。**只加「指向」类图形**（见 §2.5）。
- **首尾可循环**。④ 末尾淡出回 ① 开帧，`loop` 播放不跳。

唯一允许的转场：§3.3 里跳过 13 秒等待的那一处，0.4 秒叠化。

## 2.5 注意力引导（v3 新增，这条是你点名要的）

原则一句话：**动画只做一件事——把眼睛从「一整屏 UI」移到「那一个数/那一行/那一条结论」。** 不解释的动画一律删掉。

### 六种允许的手法

| # | 手法 | 何时用 | 精确参数 |
|---|---|---|---|
| A | **暗角聚焦** | 画面里有 3 个以上可看区域时 | 非焦点区叠 `#101614` 45% 不透明；焦点区用径向遮罩挖洞，边缘羽化 80px；亮度过渡 0.3s |
| B | **焦点框** | 要指认一个具体控件/一行表 | 1.5px 实线 `#C0632F`，圆角 4px，距目标外扩 6px；出现 0.2s 缩放 0.96→1；跟随移动 0.25s |
| C | **跟随下划线** | 表格逐行落、列表逐条出 | 2px `#C0632F`，从 0 增长到 100%，0.25s ease-out，落在**刚出现那一行**的底边 |
| D | **数字放大** | 关键数字出现时 | 该数字区域放大 1.8×，居中，停 0.8s，回到原位；放大期间四周 A 暗角 55% |
| E | **推近/平移** | ② 输入、④ 结果 | 已有；`ease-out`，0.4s 完成，不用线性 |
| F | **对比条** | 前后数字并排（如 23% → 0） | 两条等高横条，左灰右橙，宽度按数值，出现 0.35s |

### 禁止清单（做了就掉档次）

光斑 / 粒子 / emoji / 弹跳缓动 / 缩放回弹 / 彩色描边闪烁 / 手写体抖动 / 转场翻页 / 六边形科技纹 / 数字滚动跳变。

理由：这些是「模板动效」，你这两个项目的气质是审图和海图，图纸上的批注从来不抖。

## 2.6 字幕规格（v3 新增）

你说「备注字幕要大」，这条按最大可读来做。

| 项 | 规格 |
|---|---|
| 主字幕字号 | **64px**（1080p 画布），`font-weight:700` |
| 主字幕位置 | 左对齐，左边缘 160px；底边距 96px（安全区，避开播放器控件） |
| 主字幕底衬 | `rgba(246,247,244,.92)` 圆角 4px，内边距 12px 20px；不用通栏黑条 |
| 主字幕行数 | 最多 2 行，每行 ≤ 18 字 |
| 注释字号 | **36px**，`font-weight:500`，颜色 `#5F6B63`，紧贴主字幕下方 10px |
| 出现/消失 | 0.2s 淡入淡出，位置固定不动（不要上下滑，滑动的字幕会跟镜头动效打架） |
| 字体 | 思源黑体 Bold / 苹方 Bold，同网站正文一致 |

**为什么是 64 不是 56**：视频在手机上多数按 390pt 宽播放，缩放比 0.203。64px → 13px，56px → 11px。11px 在手机上是「勉强能猜」，13px 才是能读。

### 和 v3 脚本不一样的地方（如实记录）

1. **推镜没做**。2018 版的 ffmpeg 没有 `xfade`，`zoompan` 做平滑推镜代价太大。改用「下三分之一字幕带 + 大字」达到同一目的：告诉观众看哪里。视频里画面本身的滚动与逐行输出已经提供了动感。
2. **叠化改成淡出淡入**。a4 跳过 13 秒等待那段，用 0.3s 淡到纸色再淡入，视觉上是一次分段，不是硬切。
3. **暗角没做**。libass 不支持叠图片层。改成实心字幕带 —— 它本身就把注意力从画面收到底部文字上。
4. **字幕带做成实心**。半透明试过，深色界面下会透出下层 UI 文字，读起来脏。

### 图形层怎么实现的

全部走 ASS（libass），不用任何剪辑软件：
- 字幕带 = `\p1` 画的矩形，`\c` 取站上纸色 / 深墨绿
- 主字幕 64px 粗体，注释 36px，左对齐 x=300，右对齐 x=1880
- 淡入淡出 `\fad(200,200)`，数字出现带 300ms `\move` 上浮 16px
- 每片一个 `.ass`，改一个字只需改文本，重新烧一遍 20 秒

### 站里怎么接的

- 五个 mp4 + 五个 jpg **放在 `10-个人网站\` 根目录**，和 `index.html` 同级，路径写相对名
- `<video muted loop playsinline preload="none" poster="x.jpg">`
- `IntersectionObserver` 25% 进视口才 `play()`，离开 `pause()`
- `prefers-reduced-motion` 只留 poster；打印时显示「视频（打印略）」
- 海图屏三个排两列（第三个占左半行），CAD / 工厂各一个满宽 1000px
