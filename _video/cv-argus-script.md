# CV + 大模型（ARGUS）· 视频脚本 v1

素材：`08-原型素材\CV+多模态\`，四段 1728×1080 / 30fps（8:5），合计 70s
成品：`cv-argus.mp4`（1920×1080，38s，无音轨，faststart）+ `cv-argus.jpg`（960 宽海报）
风格基准：与 `factory-build.mp4` 一致 —— 底部 184px 实心字幕带 + 64px 粗体主字幕 + 36px 右注释；**无进度线、无结论闪、无全屏推镜、无大字**

---

## 一、画布规则（新增，只加在画面层，不动字幕层）

| 项 | 规格 |
|---|---|
| 画布底 | `#0E2422`（与全站 ink-block 同色） |
| 录屏卡片 | 居中、宽 1560、圆角 22px、`box-shadow 0 30px 80px rgba(0,0,0,.45)`，上下留 96px |
| 遮罩 | 卡片外径向/线性压暗到 0.18；聚焦时原画面另压一层 0.55 黑，只留聚焦区 |
| 聚焦放大 | 在卡片内部 `zoompan`，倍率 1.15–1.35，落点按镜头表；**不超出卡片边界**（超出的部分被圆角裁掉） |
| 圆角裁切特写 | 从原帧按坐标 `crop` 出一块，加 18px 圆角 + 2px `#22303C` 描边，浮在画布左下 |
| 字幕带 | 与 factory 完全一致：y=896 起 184px，纸色 `#F6F7F4`；主字幕 `\pos(300,1006)` 64px；注释右对齐 `\pos(1604,1018)` 36px |

**素材必须裁掉的四处**

1. 浏览器标签栏（含 `优化后的测试文案.md`）→ 所有镜头从 **y=140** 起裁
2. 宠物名 / 检测标签里的名字（妙妙、善善、王子、咪咪、咲咲）→ 镜头表里避开的时刻，或聚焦框只压下半场
3. 功能点4 结尾的 devtools 功能清单页 → 不用
4. 左下角 N 悬浮球、右上角扩展图标 → 随标签栏一起裁掉

## 三、拍完之后要核对的四件事

1. 每个镜头起手都从 y=140 起裁 —— 标签栏一露，整片作废
2. 遮罩不能压到主字幕带（y ≥ 896 一律不受遮罩影响）
3. 圆角卡片外不能出现录屏的白底残留（源是白底 Web，卡片外用画布底色顶掉）
4. 不用转场特效；镜头之间硬切，与 factory 一致
