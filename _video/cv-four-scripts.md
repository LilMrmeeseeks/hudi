# CV + 大模型 · 四段短视频脚本 v2（每段一个功能点）

素材：`08-原型素材\CV+多模态\`，4 段 1728×1080 / 30fps（8:5）
成品：4 个 mp4，各 12.0s，1920×1080，无音轨，faststart + 4 张 960 宽海报
风格基准：`factory-build.mp4` 的字幕层（底部 184px 实心纸色带、64px 主字幕、36px 右注释、无进度线、无结论闪）

---

## 0 共通规格

| 项 | 值 |
|---|---|
| 画布 | 1920×1080，底色 `#0E2422` |
| 去 chrome | 源统一 `crop=1728:968:0:112`（切掉浏览器标签栏，保留 ARGUS 顶栏） |
| 卡片 | `scale=1500:840` → 圆角 22px → 定位 `x=210 y=34` |
| 阴影 | 同尺寸偏移 +8，`gblur=36`，不透明度 .45 |
| 字幕带 | y=896 起 184px；主字幕 `\pos(300,1006)` 64px；注释 `\pos(1604,1018)` 36px 右对齐 |
| 段间转场 | 硬切，不加任何转场 |
| 缓入 | 放大用 0.6s 线性缓入，公式见 §5 |

**字幕时间线约定**：每段 3 条字幕，进 0.2s、出 0.2s 淡入淡出（`\fad(200,200)`）。

## 5 执行动作方案

### 5.1 一次性准备

1. 圆角遮罩 `mask-1500x840.png`（白实心、圆角 22、4× 超采样后缩）：System.Drawing 画，已可用
2. 阴影 `shadow-1500x840.png`：黑实心圆角 → `gblur=36` → alpha 0.45
3. 汇总目录：`C:\Users\MeeCreeps\_cv\{build,out,ass}`

### 5.2 单段渲染模板

```
[0:v] crop=1728:968:0:112,
      crop=w='1728/Z':h='968/Z':x='CLAMP(...)':y='CLAMP(...)',
      scale=1500:840:flags=lanczos, setsar=1  [card]
[1:v] format=gray                            [m]
[card][m] alphamerge                          [cf]
[2:v] 阴影图 → overlay(210,42)                [bg1]
color=0x0E2422:...                            [bg0]
[bg0][bg1] overlay → [bg2]
[bg2][cf]  overlay=210:34                     [v]
```

放大表达式（k = 目标倍率，T0 = 本段起始，D = 0.6）：

```
p = min(max((t-T0)/0.6,0),1)
Z = 1+(k-1)*p
x = min(max(cx*1728 - 1728/Z/2, 0), 1728-1728/Z)
y = min(max(cy*968  - 968/Z/2,  0), 968 -968/Z)
```

### 5.3 圆角放大镜（仅 cv2 段 2）

```
[0:v] 主画面 → crop 去 chrome → scale 1500:840 → eq=brightness=-0.10:contrast=0.92  [main]
[0:v] crop=300:300:cropX:cropY → scale=640:640 → alphamerge(圆角640) → pad 描边     [lens]
[bg][main_card][lens] overlay=200:300
```
`cropX/cropY` 用固定值（红框位置按抽帧测出来），不跟时间变化——放大镜本身不动，内容在动。

### 5.4 合成与检查

1. 每段 `-c:v libx264 -crf 18 -pix_fmt yuv420p -r 30` 渲染 tmp
2. `concat` 四段 → 无声母版
3. 烧 `.ass` → 出片（`-crf 21 -movflags +faststart`）
4. 海报：从**未烧字幕**母版按段中点抽帧，`scale=960:-2`
5. 核对清单（每片必过）：
   - [ ] 顶部无浏览器标签栏
   - [ ] 检测标签上无宠物名
   - [ ] cv4 尾帧无 devtools 页
   - [ ] 圆角边缘无锯齿、无白边
   - [ ] 字幕不压卡片（卡片底 ≤ 874）
   - [ ] 单文件 ≤ 2.5 MB（超了降 crf 到 24）

### 5.5 回退

- 放大抖动 → 取消 ramp，改硬切倍率
- 圆角有白边 → mask 用 4× 超采样
- 时长不够 → 只切前两段，保持 3 条字幕
